# 仕様書の見直し

依頼の仕様書は体験の核（視線を動かさず手本を見る、書き終わりに添削）を残している。下の項目は、RayNeo X3 Pro の公式制約とこの依頼の実機制約に合わせた採用判断。

## 1. 半紙の空間固定

仕様: SLAM で四隅を検出し、十字リーダーを 6DoF で半紙中央に置く。

採用: 既定は 0DoF。四隅はワンショット写真からスマホ（またはその背後の OpenCV）が出し、グラスは `Homography` で線を載せる。十字は用紙座標の中央を `paperCrosshair()` で描く。6DoF は `PlaneAnchorAdapter` が使えるビルドの明示セッションだけ。

根拠: 公式の設計規範は、X シリーズのシステムアプリを 0DoF としている。X3 Pro の SLAM は VGA の空間カメラを使い、静止画は IMX681 側である。公式 FAQ では 6DoF 中のカメラは ShareCamera 経路になる。245mAh で両方を常時回すと、この依頼が禁じている熱と連続プレビューに入る。

ずれたときはタップで取り直す。追従し続ける実装は既定にしない。

## 2. 手が離れたら撮影

仕様: 手が半紙から外れたことを検知して 12MP で撮る。

採用: 書き終わりは次のどれか。

- テンプル長押し（`TouchAction.LONG_PRESS`）
- スマホのリモコン（同じ `TouchAction` を Touch characteristic へ書く）
- Push-to-Talk の「できた」（マイクは押しているあいだだけ）

根拠: 手の離脱検知はメインカメラを開き続ける。依頼の熱制約と衝突する。

## 3. グラスからローカル PC へ直結

仕様: サーバはローカル PC の Python。通信は Wi-Fi 6 / WebSocket。

採用: グラスの通信相手はスマホだけ。Python はスマホの `AnalysisBackend` 実装であり、同じ LAN にいるときだけスマホが転送する。

根拠: スリープでグラスの Wi-Fi ソケットは切れる。グラスにキーボードが無く、PC のアドレスをグラスへ入力できない。Wi-Fi 6 である必要はなく、通常の TCP WebSocket で足りる。

## 4. 半透明ワイヤー

仕様: 外形と骨格を半透明ワイヤーで重ねる。

採用: 背景は `#000000`（消灯 = 光学的に透過）。手本は塗らない。骨格はシアン `#5CE1FF`、外形はネオングリーン `#39FF14`、添削は `#FF453A`、文は白、警告は黄。線幅の下限は 2px。

根拠: MicroLED は加算発光で、アルファを下げても現実の墨とブレンドされない。黒い画素を消すのが透過になる。公式の設計規範は 1px 線を禁止している（導波路で途切れる）。

## 5. 両眼

仕様書に未記載。

採用: 設計キャンバスは 640×480 の1枚。`BinocularPresenter` が左右へ複製する。実機では RayNeo Android SDK の `BaseMirrorActivity` をその実装にする。

根拠: 公式 Android SDK は、素の UI が左目に左半分、右目に右半分として割れると説明している。

## 6. セーフエリア

依頼: 上下左右 10%（約 48〜64px）。

公式: 合目の安全余白は左右 30px、上下 20px。距離によっては 16px まで語られる。

採用:

- 文字、警告、アドバイスは左右 64px、上下 48px（`HudCanvas.TEXT_INSET_*`）
- ゴースト線のクリップは左右 30px、上下 20px（`OPTICAL_INSET_*`）

文字を公式の 30/20 より内側へ寄せ、線は半紙の端を残すために光学余白まで使う。

## 7. 実寸の斜め上固定

仕様: サイド並置モードは手本を半紙の斜め上の空間へ実寸固定する。

採用: 0DoF のあいだは HUD 上部の線カードとして出す。`PlaneAnchorAdapter` が四隅を返しているセッションだけ空間側へ渡す。実寸は用紙プロファイルの mm（半紙は横 242、縦 333）を `CALIBRATE_COMMIT` で渡す。のしと一文字は公称値で、スマホが mm を上書きできる。

根拠: 0DoF では頭の平行移動を半紙にロックできない。

## 8. 添削の返り方

仕様: 半紙の上に赤線差分を投影し、改善アドバイス2行を HUD に出す。

採用: 赤線は画像ではなく `CORRECTION_PACK` のポリライン（用紙座標、層 `CORRECTION`）。文は最大2行、各 UTF-8 42バイト（日本語でおおよそ14文字）。結果が小さいので BLE で返し、Wi-Fi は JPEG のアップロードに限る。

VLM の待ち時間にグラスの Wi-Fi を開いたままにしない。

## 9. 音声と OS のショートカット

採用: Wake Word は置かない。X3 Pro のシステムショートカットキーは第三者アプリから変更できない、と公式の設計規範にある。キャプチャの確実な経路はスマホのボタンで、テンプル長押しはアプリのジェスチャとして使う。OS が長押しを取った機種では、スマホ側を正とする。

## 資料のゆれ

- Bluetooth は製品ページが 5.3、デバイス紹介が 5.2。契約は 5.3 専用機能を使わない
- SLAM の「カメラが使えなくなる」は X2 系の記述が混ざる。X3 Pro は VGA 空間カメラと IMX681 が別、という記述を優先し、それでも既定では SLAM をオンにしない
