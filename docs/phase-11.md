# Phase 11 — 赤い添削

写真が iPhone に出たあと、Wi-Fi を閉じてから BLE で添削を返す。Python はまだ呼ばない。`ManualCritique` が赤の一画 `(2000,2000)-(8000,8000)` と、「起筆を垂直に」「ハネを短く」を返す。

順番は、`SHOW_ADVICE`「添削中」、添削、`SHOW_ADVICE` の2行、`CORRECTION_PACK`。グラスは四隅が無くても赤線が見えるよう、用紙全体を画面に合わせる。撮影を始めると赤線は消える。

iPhone の写真は残る。画面の文言は「添削を送りました」。グラスの下は2行、線は赤。
