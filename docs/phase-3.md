# Phase 3 — HUD

640×480 を 1 枚描き、左右へ同じ絵を渡す。新しいパケットは無い。Android の `glass/` モジュールは置いていない。この環境に RayNeo SDK が無く、`BaseMirrorActivity` も `TouchDispatcher` もコンパイルできない。

描画は `renderHud`。実機ではそのビットマップを `BinocularPresenter` に渡す。SDK が無いときは `DeskMirrorPresenter` が 1280×480 の左右へ同じ画素をコピーする。

## 線と文字

背景は `HudPalette.UNLIT`（`#000000`）。画素はパレットの色だけを上書きする。アルファブレンドもアンチエイリアスも面の塗りも使わない。線幅は筆画の `widthPx`（2..8）。ブラシは正方形で、クリップの外は捨てる。

| モード | 手本・外形 | 十字 | 添削 |
| --- | --- | --- | --- |
| IDLE | 出さない | 出さない | 出さない |
| TRACE | 四隅があるとき光学クリップへ射影 | 四隅があるとき射影 | 出さない |
| SIDE_BY_SIDE | 文字セーフ上部のカードへ、用紙の縦横比で収める | 四隅があるときだけ射影 | 出さない |
| REVIEW | TRACE と同じ | TRACE と同じ | 光学クリップへ、手本の上 |

四隅が無い TRACE は線を置かない。カードへ逃がさない。

文字の色はセーフエリアの外へ出ない。上端の 1 行は接続状態（未接続なら警告色と、左上 8×8 の 2px 折れ線）。下端の 2 行は助言。状態行は接続の表示で、助言の 2 行枠とは別。

`SET_HUD` の輝度は画素に混ぜない。混ぜると黒との中間色ができ、消灯とパレットが崩れる。輝度は `PracticeHud.brightness` に保持し、線幅と十字の有無だけを描画に使う。

フォントは `shodo.hud.font`、環境変数 `SHODO_HUD_FONT`、無ければ文泉驛マイクロ黒か Droid Sans Fallback。日本語を描けないフォントでは描画を始めない。

## タッチ

`PracticeHud` が `TempleInputSink`。受けるのは `TouchAction` だけ。生の MotionEvent は SDK がジェスチャにしてから渡す。スマホの Touch 書き込みも同じメソッド。

| 操作 | 結果 |
| --- | --- |
| タップ | 四隅が無ければ `StartCalibration`。添削中ならレッスンのモードへ戻し、赤線を消す |
| 長押し | `FinishAndCapture`。カメラは開かない |
| ダブルタップ | オーバーレイと助言を消す |
| トリプルタップ | 待機からなぞりへ。以降はなぞりと並置を交互に。添削中はレッスンの反対側へ出る |
| 前後スワイプ | 手元の手本を切り替え、`ShiftExemplar` を出す |
| 上下スワイプ | 助言のページ |

## 動かし方

```bash
./gradlew :protocol:test
```

見るものは、水平線の太さが 2px 以上であること、文字と警告が文字セーフの内側であること、並置の緑がカード内で十字がカードの下へ出ること、添削色が光学クリップ内であること、左右の画素が一致すること、タップと長押しとページ送り。
