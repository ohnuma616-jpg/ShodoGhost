# HUD と入力

## キャンバス

設計サイズは 640×480。アプリはこの1枚を描き、`BinocularPresenter` が両眼へ複製する。

| 領域 | 矩形 | 用途 |
| --- | --- | --- |
| キャンバス | 0,0 – 640×480 | 描画バッファ |
| 文字セーフ | 左右 64、上下 48。内側 512×384 | アドバイス、状態、警告 |
| 光学クリップ | 左右 30、上下 20。内側 580×440 | ゴースト線がはみ出してよい限界 |

文字セーフは依頼の 10%。光学クリップは RayNeo 設計規範の合目余白。線を 10% まで削ると半紙の端が欠けるので、線と文字で余白を分けた。

仮想像の距離は公式が 1.7m 以上を推奨している。0DoF の HUD は OS の表示距離に乗せ、アプリは独自の近距離レイヤを作らない。

## 色

背景は `#000000`。この画素は消灯で、現実が透過する。面の塗り、ドロップシャドウ、アルファによる「半透明の紙」は使わない。

| 役割 | 色 | 定数 |
| --- | --- | --- |
| 骨格 | `#5CE1FF` | `HudPalette.EXEMPLAR` |
| 外形 | `#39FF14` | `HudPalette.CONTOUR` |
| 添削 | `#FF453A` | `HudPalette.CORRECTION` |
| 十字 | `#5CE1FF` | 骨格と同じ |
| 文 | `#FFFFFF` | `HudPalette.TEXT` |
| 警告 | `#FFD60A` | `HudPalette.WARNING` |

線幅は 2..8px。既定 2。`SET_HUD` で変える。上下スワイプはアドバイスのページ送りで、線幅変更はスマホの設定から `SET_HUD` を送る。

トレースモードは骨格と外形を半紙四隅へ射影する。サイド並置でアンカーが無いときは、同じ筆画を文字セーフ上部の矩形へ収め、半紙の中央十字だけを射影する。レビューは添削層を足し、下端セーフに2行を出す。

情報は同時に「線」と「2行」まで。手本選択の一覧はグラスに出さない。一覧はスマホ。

## タッチ

X3 のテンプルは一次元の MotionEvent で、SDK の `TouchDispatcher` がジェスチャにする。業務コードは生の座標を見ない。`TempleInputSink` が `TouchAction` を受け、`toGuideCommand()` で意味にする。スマホのリモコンも同じ列挙を Touch characteristic に書く。

| ジェスチャ | `TouchAction` | 意味 |
| --- | --- | --- |
| シングルタップ | `CLICK` | 決定。キャリブの開始、レビューを閉じる |
| 長押し | `LONG_PRESS` | 書き終わり。撮影へ進む |
| ダブルタップ | `DOUBLE_CLICK` | 戻る。オーバーレイを消す。公式も戻る操作にダブルタップを推奨している |
| トリプルタップ | `TRIPLE_CLICK` | TRACE と SIDE_BY_SIDE を循環 |
| 前スワイプ | `SLIDE_FORWARD` | 次の手本。スマホがパックを送る |
| 後スワイプ | `SLIDE_BACKWARD` | 前の手本 |
| 上スワイプ | `SLIDE_UP` | アドバイスの次ページ |
| 下スワイプ | `SLIDE_DOWN` | 前ページ |

X3 Pro のハードウェアショートカットキーはアプリから変更できない。長押しが OS に取られる個体では、撮影の正はスマホのボタン。

音声は Push-to-Talk。長押しとは別に、スマホが録音開始を指示した区間だけマイクを開く。Wake Word の常駐はしない。PTT の「できた」は `CaptureReason.PTT` の `CAPTURE_NOW` と同じ撮影経路に入る。

## 描画順

1. バッファを `#000000` でクリアする
2. 四隅があるとき、十字と手本を射影して光学クリップ内に線を引く
3. 添削層をその上に引く
4. 文字セーフの下端にアドバイス、上端に接続状態を1行

未接続の警告は上端の1行と、左上セーフ内の 8×8 の黄色い折れ線だけにする。ビットマップアイコンは置かない。
