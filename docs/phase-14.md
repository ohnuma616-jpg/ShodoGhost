# Phase 14 — 半紙の四隅

撮影した JPEG が届き、Wi-Fi を閉じたあと、iPhone が輝度から半紙の四隅を出す。OpenCV は同梱しない。長い辺を 160px まで縮め、大津の閾値で明るい塊を取る。左上は x+y の最小、右上は x−y の最大、右下は x+y の最大、左下は x−y の最小。それを用紙座標 0..10000 にする。

明るい画素が画面の 8% 未満、または 85% を超えるときは出さない。隣り合う隅の距離が 800 未満、または面積が 1500×1500 未満のときも出さない。机と紙の境が無い写真は、四隅を動かさない。

見つかったときは `CALIBRATE_COMMIT`（ワンショット、半紙 242×333mm）を送る。画面は「四隅を合わせ、添削を送りました」。見つからないときは「四隅は見つからず、添削を送りました」。そのあと今までどおり `ManualCritique` の赤線と助言を送る。「四隅を送る」は内側 10%–90% の手送りのまま。

グラス側の APK は変えない。既にある `CALIBRATE_COMMIT` が十字と射影を更新する。
