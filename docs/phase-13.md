# Phase 13 — 手本

iPhone の「手本を送る」が `SET_MODE`（なぞり、半紙）のあと、`EXEMPLAR_META` と `STROKE_PACK` を送る。中身は毛筆の「永」の外形。点と本体の 2 本。検出はまだしない。線は外形なので緑、幅 2px。中は塗らず、半紙が透ける。武蔵賞状楷書体の文字データは、使用許諾が抜き出しを禁じているので使っていない。

グラスは下に「手本」と出す。四隅があればその中へ射影し、シアンの十字も残す。四隅が無いときは用紙全体に置く。撮影で消えるのは赤線と助言だけ。緑の永と十字は残る。次の赤線はその上に重なる。

再接続で手本ビットが落ちていれば、直前のパックを 1 回送り直す。
